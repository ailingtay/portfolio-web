01 / Start with the tools

First, make the tools.
Then, make the timers.

I started with the countdown itself. Across 45 timers, the same setup would repeat again and again. Before exploring the visual worlds, I built and tested tools to handle that setup while keeping the design editable.

Experiment A / Browser timer generator

It worked.
I missed the craft.

I used Claude to build a browser timer generator. It could produce a countdown, but I missed the control over typography, animation and finish.

Experiment B / After Effects setup tool

Repeat the setup.
Keep the decisions.

The next approach brought the repeated setup into After Effects. The timer structure could be generated while the visual decisions stayed in the composition.

Tool recordingMotion unavailable · still shown

Custom setup tool → Editable After Effects composition

Under the hood

Separate the timer logic from the design.

Input
Duration, placement and visual settings. These become the repeated setup rather than a new composition built from scratch.
Handoff
The browser experiment produces a timer export. The After Effects tool produces a structure that remains editable in the composition.
What to check
Change the duration, then change the typography. Can you make both adjustments without rebuilding the scene?

Try it yourselfBegin with a plain countdown. Make two different durations, then apply two visual treatments. Notice which settings should belong to the tool and which should stay in the composition.

With the setup in place, I could start exploring how each timer would look and move. From tools to animation ↓

02 / One drawing, three stages

004 — Disco dance

Under the hood

A reference is a set of constraints.

Input
One character drawing: a clear silhouette, fixed colours and recognisable proportions.
Handoff
The drawing becomes the reference for generated motion. The selected clip is then placed into the finished countdown composition.
What to check
Scrub through the movement. Look at the eyes, outline and feet: do they still belong to the same character from frame to frame?

Try it yourselfUse one character and ask for one small action. Keep the drawing fixed between attempts so the effect of changing the motion direction is easier to compare.

03 / Working notes

Different ideas.
Different ways in.

The interesting part was working out which approach suited each world. Some began with a drawing. Others needed sprites, separate layers, or a series of motion tests.

006

Illustration × creative coding

A little cast of characters.

From a sheet of characters to a sprite workflow: a way to test small movements before putting the whole cast into a scene.

Tool combinationCharacter assets → Claude-assisted sprites → Animation prototype → Timer composition

Under the hood

Separate the character frame from its movement.

Input
A character sheet and a small set of image frames. A sprite is an image used as a movable element in an animation.
Handoff
Claude-assisted tests explore the frames and preview the animation in code. The prototype makes it possible to review the behaviour before finishing the scene.
What to check
Look for a stable outline and consistent scale. Then compare the individual character with the same movement repeated across the cast.

Try it yourselfStart with one character and two frames. Preview the frame change in place before adding travel across the scene. This makes an unwanted jump easier to spot.

Under the hood

Build duration from layers of behaviour.

Base loop
The resting character provides a repeating foundation. This handles the long quiet stretch of the timer.

04 / A change of pace

Leave room
for quieter things.

The same project also made room for light linework, paper textures and gentler movement. These experiments combine prepared assets with Claude-assisted animation.

Tool combinationPrepared illustration → Generated motion elements → Claude-assisted animation → Composition

Under the hood

Prepare layers around what needs to move.

Input
Separate scene elements: the seascape’s illustrated pieces, or the watercolour jar’s front, back, stones and paper texture.
Handoff
Prepared assets go into a Claude-assisted animation prototype. Separating the pieces gives each moving element its own place in the scene.
What to check
Watch where elements overlap. In the jar study, notice how the stones read as being inside the glass rather than sitting on top of the image.

Try it yourselfChoose a foreground, one moving object and a background. Test their ordering with a single movement before adding more objects.

023 — Dinosaurs / From selected image to moving scene

Under the hood

Review the still and the motion separately.

Still-image choice
Compare composition, palette and how clearly the egg reads. The four saved image directions make those differences visible.
Asset preparation
The egg and its setting are separated before motion tests. This creates a distinct moving element and a background to place it against.
Motion review
Check the moving object in the final scene as well as on its own. A good still does not yet tell you whether the animation is usable.

Try it yourselfUse the same visual brief for a few image directions. Write down why you prefer one before animating it, then review the motion against that decision.

06 / Directed generation

Small movements.
Specific decisions.

For the library scene, I tested how much movement the owl could have while keeping its shape, setting and props consistent. Each rejected take helped make the direction more specific.

Under the hood

Review what should stay still, too.

Hold constant
Character shape, camera framing, props and the isolated background. The owl’s rejected tests show where those constraints drifted.
Allow to move
The chosen action. Keep the intended performance specific enough that unwanted movement is easier to identify.
Compose
Combine selected elements into the library scene. Compositing means assembling those separate image and motion layers into one result.

Try it yourselfPause the rejected and selected owl clips at several points. Compare the book count, framing and silhouette before judging how appealing the movement is.

Animal dance / Directed motion

Individual moves.
One shared rhythm.

For Animal Dance, I explored a cast of animal musicians and dancers, then gave each character its own motion direction. The separate performances come together in the finished treehouse timer.

Under the hood

Design the cast before directing the performance.

Input
Sheets of animal musicians and dancers, exploring different silhouettes, poses, costumes and instruments.
Handoff
Individual references are isolated before being connected to their own motion instructions. The full timer brings those separate performances together.
What to check
Compare the instrument, hands and outfit across a moving clip. Keep an eye on details that change shape or appear and disappear.

Try it yourselfBuild a small cast around one visual style. Choose one character, give it a single action, and inspect that clip before introducing the rest of the cast.
